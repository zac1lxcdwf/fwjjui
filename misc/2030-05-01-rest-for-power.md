# Rest for Power

[by resting longer between](https://glp-insights.xianfengchem.com/blog/6434250594.html)

Don't rush through intervals. Longer recovery periods between sprints provide greater speed gains, according to a study in the Journal of Strength and Conditioning Research. English researchers had 25 fit men complete a set of cycling sprints with either 10- or 30-second rest periods.

The longer rest resulted in a 26 percent increase in power and a 16 percent decrease in fatigue, compared with the 10-second group. The shorter recovery didn't allow heart rate to return to normal, so the session became an endurance workout, says study author Mark Glaister, Ph.D., a lecturer at St. Mary's College. Use long recovery periods to build speed, he says, and short ones to improve endurance.
